NEPTRON licence notes, Raspberry Pi image
=========================================

This image
----------

- NEPTRON release: @NEPTRON_RELEASE@
- NEPTRON commit: @NEPTRON_COMMIT@
- Commit date: @NEPTRON_DATE@
- Variant: @NEPTRON_VARIANT@

The commit names the NEPTRON source that built this image, in the
public repository github.com/paologaleotti/neptron. A commit that ends
in `-modified` was built from a tree with changes that are not in that
commit. "unknown" means that the build did not know the value. The date
is the date of the commit, not of the build. The same values are in the
file `/etc/neptron-release` inside the image.

Licences
--------

This image contains programs under different licences. Three libretro
cores, FinalBurn Neo, Snes9x and Genesis Plus GX, may not be sold or used
commercially under their own licences. So this image, which contains
them, may not be sold. Every other program in this image keeps its own
licence, and its rights are not reduced. Remove those three cores
(`fbneo_libretro.so`, `snes9x_libretro.so` and
`genesis_plus_gx_libretro.so` in `/usr/lib/libretro`) to redistribute
the rest under its own terms.

The NEPTRON programs
--------------------

- `neptron`: the frontend.
- `neptronctl`: the command-line client and the self-test of the bench.
- `neptron-launch`: the launcher.

The NEPTRON source code is under the MIT licence or the Apache License
2.0, at your option (`LICENSE-MIT`, `LICENSE-APACHE`).

`neptron` and `neptronctl` contain Switchres
(github.com/antonioginer/switchres, commit
09272ac24640daee45f5be15b1b856ecd220dda2), by Chris Kennedy, Antonio
Giner, Alexandre Wodarczyk and Gil Delescluse, under the GNU General
Public License 2.0 or later. So these two programs are under the GNU
General Public License 3.0 or later. The texts are in the folders
`legal/licenses/neptron-0.1.0` and `legal/licenses/neptronctl-0.1.0`:
`LICENSE-GPL-3.0` for the programs, and `vendor/switchres/LICENSE` for
Switchres. The other NEPTRON programs contain no Switchres code and are
under the MIT licence or the Apache License 2.0, at your option.

`neptron` also contains the Spleen font by Frederic Cambus, under the
BSD 2-Clause licence. Its notice is in `legal/licenses/neptron-0.1.0`,
file `crates/neptron-ui/assets/fonts/spleen/LICENSE`.

`neptron`, `neptronctl` and `neptron-launch` are written in Rust. Each
one contains the Rust standard library and crates from crates.io, each
under its own licence (MIT, Apache-2.0, ISC, zlib and others). The
files `legal/neptron-rust/<program>.txt` on this partition list them,
with their licence, notice and copyright texts. The same files are in
`/usr/share/licenses/neptron-rust` inside the image.

The image also holds other software. Each package keeps its own licence.
The folder `legal` on this partition lists them:

- `legal/manifest.csv`: every package, its version, its licence and its
  licence files. It is the output of `make legal-info` of Buildroot.
- `legal/licenses/<package>`: the licence texts of each package.

The same texts are in `/usr/share/licenses` inside the image.

The monitor presets in `/usr/share/neptron/monitors` come from Switchres
too and are under the GNU General Public License 2.0 or later. The
frontend reads them at run time and does not contain them.

The gamepad mappings in `/usr/share/sdl-gamecontrollerdb` come from the
community database SDL_GameControllerDB
(github.com/mdqinc/SDL_GameControllerDB, commit
a69b1ac650f4faab73596c2d561edc2c7636978e), unchanged. They are under the
zlib licence. Its text is in `legal/licenses/sdl-gamecontrollerdb`. The
frontend reads them at run time and does not contain them.

The kernel and the device trees
-------------------------------

The kernel is the Raspberry Pi fork of Linux (github.com/raspberrypi/linux,
branch rpi-6.18.y, commit ea17ae02ca28483e508b05c7c44190c01a1ef8eb, Linux
6.18.62), under the GNU General Public License 2.0 only. `Image`, the
device trees (`bcm2710-*.dtb`) and the overlays (`overlays/*.dtbo`) on
this partition are built from that source. The kernel has no patch: in
particular, not the 15 kHz patch set of the PC image, which changes PC
graphics drivers that this kernel does not use.

Libretro cores
--------------

- FCEUmm (`fceumm_libretro.so`): GNU General Public License 2.0 or later.
- Snes9x (`snes9x_libretro.so`): the Snes9x licence. It allows use and
  copies free of charge, and it does not allow commercial use or sale.
- Genesis Plus GX (`genesis_plus_gx_libretro.so`): the Genesis Plus GX
  licence. It allows use and copies free of charge, and it does not allow
  commercial use or sale. Its `LICENSE.txt` names these parts, each
  under its own licence:
  - The Nuked OPN2 core, the NTSC filter and Blip Buffer: the GNU Lesser
    General Public License 2.1 or later. The written offer below covers
    their source.
  - Tremor and libchdr (with Zstandard): the BSD 3-Clause licence.
  - minimp3: CC0 1.0.
  - dr_flac: the MIT licence. zlib: the zlib licence. The LZMA decoder:
    public domain.
  The licence folder of the image holds `LICENSE.txt`, with the full
  text of the LGPL, under `libretro-genesis-plus-gx`.
- FinalBurn Neo (`fbneo_libretro.so`): the FB Neo licence, with the MAME
  licence. It allows use and copies free of charge. It does not allow
  sale or any other monetary profit, and it does not allow requests for
  donations for a project that uses its source code. Changes to its
  source code must be public; this image has none. The library also
  contains these parts, each under its own licence:
  - zlib and MiniZip: the zlib licence.
  - libretro-common: the MIT licence.
  - uGUI: its own licence (free use, keep the copyright notice).
  - The Source Han Sans font (a bitmap copy): the SIL Open Font
    License 1.1.
  - libchdr: the BSD 3-Clause licence.
  - The LZMA decoder of the LZMA SDK: public domain.
  - Zstandard (the decoder): the BSD 3-Clause licence or GPL 2.0, at
    your choice.
  - dr_flac, dr_mp3 and dr_wav of dr_libs: public domain (Unlicense)
    or MIT No Attribution, at your choice.
  - stb_vorbis: the MIT licence or public domain, at your choice.
  The licence folder of the image holds the text of each one, under
  `libretro-fbneo`.
- The list of arcade games (`/usr/share/neptron/arcade/fbneo.idx`) is
  made from the game list (DAT) in the source of FinalBurn Neo. It is
  under the FB Neo licence too.

The frontend opens one core at a time in its own process, through the
libretro API. Each core is a separate library, built from its own
source; the frontend contains no core code (ADR 0019 of NEPTRON). The
owner of NEPTRON accepted the licences of Snes9x, Genesis Plus GX and
FinalBurn Neo for a free image that is never sold. NEPTRON takes no
donations, as the FB Neo licence asks.

Network share
-------------

The network share (SMB) uses these programs:

- The SMB server `ksmbd` is part of the kernel: GNU General Public
  License 2.0 only.
- `ksmbd-tools` (`ksmbd.mountd`, `ksmbd.control`): GNU General Public
  License 2.0 or later.
- GLib (`libglib2`) and `libnl`, which `ksmbd-tools` needs: GNU Lesser
  General Public License 2.1 or later. GLib also uses PCRE2 (BSD
  3-Clause licence) and libffi (MIT licence).
- `mdnsd`, which gives the name `neptron.local` on the network: BSD
  3-Clause licence.
- `iptables`, which limits the share to the local network: GNU General
  Public License 2.0.

What may be distributed
-----------------------

This image may be distributed free of charge, unchanged, for use on a
Raspberry Pi, with this file, the folder `legal`, and the source code
below. It may not be sold, because it contains the three cores named at
the top of this file. Its firmware files may not be changed or used on
other hardware (the firmware licence above). Every other program keeps
the rights of its own licence.

Source code
-----------

The image contains software under the GNU General Public License and
the GNU Lesser General Public License. The source code of each of these
packages, at the version and with the patches that the image uses, is
the `make legal-info` output of the build of the image. The kernel
source is the archive of the Raspberry Pi fork at the commit named
above, in the kernel folder of `sources`. The kernel of this image
applies no patch. The project gives out that source together with the
image, from the same place. The written offer below applies in every
case, also for an image that reached you without its source.

The firmware files above are binary only. They have no source, and the
written offer does not cover them.
