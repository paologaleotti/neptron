NEPTRON licence notes
=====================

NEPTRON is open source and not commercial. This image is free of charge.
Nobody may sell it, or sell a device or a service because it holds it.

The NEPTRON programs are under the MIT licence or the Apache License
2.0, at your option:

- `neptron`: the frontend.
- `neptron-launch`: the launcher.
- `neptronctl`: the command-line client and the self-test of the bench.
- `neptron-capture` and `neptron-vkms-probe`: test tools for the
  virtual display of QEMU. They refuse to run on any other display.

The image also holds other software. Each package keeps its own licence.
The folder `legal` on this partition lists them:

- `legal/manifest.csv`: every package, its version, its licence and its
  licence files. It is the output of `make legal-info` of Buildroot.
- `legal/licenses/<package>`: the licence texts of each package.

The same texts are in `/usr/share/licenses` inside the image.

The monitor presets in `/usr/share/neptron/monitors` come from Switchres
and are under the GNU General Public License 2.0 or later. The frontend
reads them at run time and does not contain them.

The gamepad mappings in `/usr/share/sdl-gamecontrollerdb` come from the
community database SDL_GameControllerDB
(github.com/mdqinc/SDL_GameControllerDB, commit
a69b1ac650f4faab73596c2d561edc2c7636978e), unchanged. They are under the
zlib licence. Its text is in `legal/licenses/sdl-gamecontrollerdb`. The
frontend reads them at run time and does not contain them.

Network share
-------------

The network share (SMB) uses these programs:

- The SMB server `ksmbd` is part of the kernel: GNU General Public
  License 2.0 only.
- `ksmbd-tools` (`ksmbd.mountd`, `ksmbd.control`): GNU General Public
  License 2.0 or later.
- GLib (`libglib2`) and `libnl`, which `ksmbd-tools` needs: GNU Lesser
  General Public License 2.1 or later. GLib also uses PCRE2 (BSD
  3-Clause licence) and libffi (MIT licence).
- `mdnsd`, which gives the name `neptron.local` on the network: BSD
  3-Clause licence.

Firmware
--------

The development variant of the image holds the firmware of the Realtek
RTL8168 Ethernet chips (`/lib/firmware/rtl_nic`) from the package
linux-firmware. Realtek allows the distribution of these files with
their copyright notice. The notice is in the file `WHENCE` of
linux-firmware, in `legal/licenses/linux-firmware`. The release image
holds no firmware.

The kernel and the 15 kHz patch set
-----------------------------------

The kernel is Linux 6.18.63, under the GNU General Public License 2.0
only. The PC image is built in two variants, and this file goes into
both:

- The image with the 15 kHz patch set (the default build) applies the
  nine patches below to the kernel.
- The image built with `cargo xtask os build --arch x86_64
  --no-kernel-15khz` applies no kernel patch.

The file `grub.cfg` on the boot partition tells them apart: the root is
PARTUUID 4e505452-02 or 4e505444-02 in an image with the set, and
4e50544e-02 or 4e505445-02 in an image without it.

The 15 kHz patch set of D0023R:

- Source: github.com/D0023R/linux_kernel_15khz, folder `linux-6.18`.
- Commit: d85a343379f7f54155f69ef56dc544b666635894.
- Patches, applied in this order: 01_linux_15khz.patch,
  02_linux_15khz_interlaced_mode_fix.patch,
  03_linux_15khz_dcn1_dcn2_dcn3_interlaced_mode_fix.patch,
  04_linux_15khz_dce_interlaced_mode_fix.patch,
  05_linux_15khz_amdgpu_pll_fix.patch,
  06_linux_switchres_kms_drm_modesetting.patch,
  07_linux_15khz_fix_ddc.patch, 08_linux_15khz_interlace_force_even.patch,
  09_linux_15khz_i915_gen9_interlace.patch.
- Licence: GNU General Public License 2.0 only, the licence of the
  kernel. The LICENSE file and the README of the patch repository state
  it at that commit. The two files that patch 01 adds also carry the
  MIT-style notice of the DRM files of the kernel.

Source code
-----------

The image contains software under the GNU General Public License and
the GNU Lesser General Public License. The source code of each of these
packages, at the version and with the patches that the image uses, is
the `make legal-info` output of the build of the image. The kernel
source is in its folder `sources/linux-6.18.63`: the kernel archive, the
patches that this image applies (none in the image without the set) and
the file `series` with their order. The project gives out that source
together with the image, from the same place. The written offer below
applies in every case, also for an image that reached you without its
source.
