# NEPTRON 0.1.1

NEPTRON is an operating system for retro games on a CRT or a flat panel. It starts from a USB stick or an SD card, shows a menu for a pad or an arcade stick, and gives each game a display mode with the game's own lines and speed where the monitor allows it.

This is the first version, an early milestone. Version 0.1.1 is version 0.1.0 with a correction to the release build; the two behave the same, and 0.1.0 has no images. Versions 0.x work and anyone can use them, but they are not complete: the first release for the public is 1.0. The checks of the build pass on this version. A test of these images on real monitors is still to come, so use a monitor that you can afford to risk, and read the safety section below.

## What it does

- **Systems:** NES (FCEUmm), SNES (Snes9x), Mega Drive (Genesis Plus GX), arcade and Neo Geo (FinalBurn Neo).
- **Displays:** a 15 kHz CRT, a 31 kHz PC CRT, a flat panel, and a TV on composite (Raspberry Pi).
- **Picture:** one setting, "Picture mode", with Auto, Sharp lines, Game speed, Fit, Native and whole multiples, and "Refresh rate" with Auto, Double rate, 50 Hz and 60 Hz. An option that the monitor cannot show safely is grey and says why.
- **Monitor safety:** every mode is checked against the monitor's profile before it is set. A change of the monitor asks "Keep this picture?" and goes back after 15 seconds with no answer. Hold Select and Start for 5 seconds to go to the safe mode with no picture.
- **Controllers:** XInput pads, PS3 arcade sticks, generic pads with a guided button mapping, two players by plug order.
- **Games:** copy ROMs to the `NEPTRON` share partition from a computer, or over the network share. Save RAM is written during play and kept with one backup per session.
- **TATE:** a setting for the orientation of the screen (0, 90, 180, 270). The menu has a portrait layout for a turned screen, and a vertical arcade game fills it at its own lines. Each game can take its own orientation.
- **Other:** scanlines with an automatic rule, a screensaver, a quick menu in a game (hold Select and Start for half a second), first-boot settings in `neptron.toml` on the boot partition.

## Hardware

- **PC image:** a 64-bit PC with Intel graphics. Tested on an i3-6100T. AMD and other graphics cards are not tested and can show no picture.
- **Raspberry Pi image:** Raspberry Pi 3 B and B+.

## Install

1. Download the image for your machine and its `SHA256SUMS`.
2. Unpack the `.img.xz` file and write the image to a USB stick (PC) or an SD card (Pi) with a tool such as `dd` or balenaEtcher.
3. Start the machine from it. The first start makes the share partition in the free space.
4. Copy your own ROM files to the share.

## Read this before you connect a 15 kHz monitor to a PC

From power-on until the NEPTRON menu appears, the firmware of the PC drives the output in its own mode, at 31 kHz or more. NEPTRON cannot blank that. Switch a monitor that takes 15 kHz only on, or connect it, after the menu appears, unless you know that the output of your PC at power-on is safe for it. The README has the full safety section.

## Known limits

- No save states, no netplay, no shaders, no box art.
- On a screen that is not turned, a vertical arcade game shows upright and small, or as large as the screen allows with the picture mode Fit.
- On a TV, the menu has a black band at each side.
- A PC with a 15 kHz CRT shows no interlaced mode on Intel graphics.
- The power button of a PC does nothing. Use "Shut down" in the menu.
- The network share works only for computers on a private IPv4 network (`192.168.x.x`, `10.x.x.x`, `172.16` to `172.31`).
- A game that the machine cannot run at full speed shows a notice in the quick menu.

## Licences

Each image holds programs under different licences. FinalBurn Neo, Snes9x and Genesis Plus GX may not be sold or used commercially, so an image may not be sold. Every other program keeps its own licence. `LICENCES.txt` on the boot partition of each image gives every licence, the commit of the build and the written offer for the source. The source of each image is the `-sources.tar` file beside it.
